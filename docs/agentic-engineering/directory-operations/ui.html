UI-001: Nested creation prompt

Press a in focused tree navigation. Groot captures the current destination before opening this native prompt.

Empty state

Create in …/src:

Enter a relative path. End the path with / to create a directory.

File path state

Create in …/src: some/new/directory/file.md

Enter creates missing directories and one final empty file.

Directory path state

Create in …/src: some/new/directory/

Enter creates missing directories and selects the final collapsed directory.

Error state

Create in …/src: some/../file.md
Cannot create path: traversal components are not allowed.

The prompt closes. Created parent directories remain after a later filesystem failure.

Narrow state

Create: some/new/file.md

The label shortens before input space. The submitted path remains unchanged.

Input map

  • Enter: Submit the complete path.
  • Escape or Ctrl-C: Cancel without filesystem changes.
  • Native editing keys: Edit the path.

Creation runs synchronously. No loading state appears.
