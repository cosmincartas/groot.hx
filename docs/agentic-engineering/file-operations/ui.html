Submission

Success

Refresh the tree and select the renamed entry. Do not open an editor buffer.

Error

Groot              │ Editor
▾ src/             │
  main.scm         │
─────────────────────────────────────

Use the host error area for invalid names, collisions, and filesystem failures.

The prompt closes after submission, including failure. Press r to retry with the current selection.

Cancelled

Keep the previous tree selection. Do not change the filesystem.

Normal tree input resumes after submission or cancellation.

UI-3: Permanent delete confirmation

These delete mocks extend the retained rename reference above. The host controls prompt placement and styling.

File selected: empty input

Groot              │ Editor
▾ src/             │
  main.scm         │
────────────────────────────────────────────────────────────
Permanently delete src/main.scm? Type yes: ▏

Directory selected

Permanently delete src/ and ALL contents? Type yes: ▏

ALL contents includes hidden and explorer-excluded entries. The confirmation does not count entries.

Symbolic link selected

Permanently delete link current? Type yes: ▏

Delete the link only. Keep its target unchanged.

Confirmation input

Permanently delete src/ and ALL contents? Type yes: yes▏

Enter submits and closes the prompt. Only exact lowercase yes authorizes deletion.

Empty input, other text, Escape, or Ctrl-C cancels without filesystem changes.

Narrow editor

Permanent delete …/src/ +ALL? yes: ▏

Shorten the target label, not the permanent-deletion warning or directory-contents warning.

Keep the selected row visible behind the prompt. Preserve space for yes input.

Insufficient display space

Cannot show delete confirmation. Widen the editor.

If the warning and usable input cannot fit, reject the request without deletion.

Check width before opening and again before deletion. Reject submission if a resize leaves insufficient space.

Submission and cancellation

Capture the selected path and kind before opening the prompt. Do not change the target during input.

Use native prompt editing and paste controls. The host consumes mouse input while the prompt remains open.

No separate progress widget exists. Escape cancels before submission, not after deletion starts.

UI-4: Delete result

Success

Groot              │ Editor
▾ src/             │
  remaining.scm    │

Refresh the tree and select the surviving parent. Preserve editor document focus.

Empty parent

Groot              │ Editor
▾ src/             │

Keep the empty parent selected. Deleting its final child does not delete the parent.

Parent disappears externally

Select the nearest surviving ancestor within the captured root.

Root unavailable

Explorer root unavailable. Could not select a surviving parent.

Keep selection clamped. Do not recreate directories or select an ancestor outside the root.

Open-document rejection

Cannot delete src/: it contains an open document.

Invalid or changed target

Cannot delete src/main.scm: the target is missing or changed.

Report root, outside-root, and unsupported-target rejection through the host error area.

An empty selection opens no prompt and makes no filesystem changes.

Deletion failure

Could not delete src/main.scm: permission denied.

Possible partial deletion

Could not finish deleting src/: permission denied.
Some contents may already be deleted. No rollback occurred.

Stop deletion and attempt to refresh the remaining entries. Do not report complete success.

Display failure after deletion

Deleted src/main.scm, but the tree could not refresh.
Press R to refresh.

Do not restore entries or repeat deletion because display failed.

Cancelled

Close the prompt and preserve the filesystem and selection. Resume normal tree input.

Retry

After an error, inspect the remaining entries. Press d to request deletion of the current selection again.

On narrow displays, let the host render errors. Do not replace detailed errors with success messages.
